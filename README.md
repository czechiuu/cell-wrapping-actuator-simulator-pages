# 细胞包裹执行器仿真器

本仓库是 GitHub Pages 的静态发布仓库。

当前界面将铰链外形与 Pd–Au 驱动参数放在同一个“主动铰链 / Pd–Au 执行器”入口，并默认显示所选面板对应的曲率、转角、力矩、接触力和压强。

## 参数关系

| 输入 | 物理意义 | 参与计算 |
| --- | --- | --- |
| 弯曲段长度 L | 裸露双层金属沿弯曲方向的有效长度，不含刚性面板 | 自由转角 κ₀L、平均受限曲率 θ/L |
| 单条宽度 w、并联条数 n | 同一铰链内共同转动的金属条 | 有效金属宽度 n×w、EI、主动弯矩 |
| Pd/Au 层厚与杨氏模量 | 两层实际金属截面 | 中性轴、EI、自由曲率 |
| 铰链外形宽度、示意厚度 | 三维显示的连接段外形 | 几何显示，不作为金属截面计算 EI |
| 每侧面板数 | 每个面板前有一个主动铰链 | 每侧铰链数与面板数相同 |

当前核心没有独立的 split hinge 分节模型，也没有额外计入被动铰链层的刚度。

## 为什么默认没有有效压强

初始参数为教学值：Pd/Au 各 100 nm，杨氏模量分别 120/80 GPa，应变差 0.1%，弯曲段长 30 µm。其自由曲率是 7422.680412 m⁻¹，自由转角是 **12.758648°**。

默认几何指定的第一节转角约 129.58°，串联平衡出现负法向试算力。无黏附压缩模型不能将负力当作有效压力，因此接触力和压强保持无效；界面仍展示已经算出的截面量、曲率与力矩。

“教学示例”可以展示一组完整的名义载荷，但会恢复默认几何并设置逐节自由曲率，未经实验校准。使用前可导出当前配置。

## 计算范围

本程序计算的是**给定姿态下的近似名义载荷**。它未联立求解细胞变形、真实接触、脱离与器件的最终平衡姿态。有限长铰链的平均力臂采用中点近似。详细核对见 [模型核对](docs/model-audit.md)。

## 维护与验证

发布仓库原本只有编译产物，没有上游应用源码。本次保留 0.2 核心的计算与三维代码，只移除原来的页面挂载语句，并导出一个固定的兼容接口：

- `assets/simulator-core-v0.2.js`：原发布核心，计算公式不变。
- `assets/simulator-ui.js`：可直接编辑的参数与结果界面，无构建依赖。
- `assets/result-view.js`：数值格式、诊断与 CSV 导出。
- `assets/simulator-ui.css`：界面布局。

将这些界面变更迁回上游源码后，应由上游构建替代本兼容接口；不要无条件覆盖核心文件，否则符号接口会失效。

在 Node.js 20 或更新版本执行：

```sh
npm test
npm run check
```

本地预览可在仓库目录执行 `python -m http.server 8765`，再打开 `http://localhost:8765/`。

自动核验覆盖逐层截面关系、12.76°教学例、0.747 Pa 单面板算例、应变符号、并联数量/长度缩放、负力处理、逐节设置、串联平衡和导出。浏览器视觉与交互检查仍需在可访问本地预览的浏览器中完成。
