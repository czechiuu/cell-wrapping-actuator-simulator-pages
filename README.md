# Cell Wrapping Actuator Simulator · v0.3

[打开仿真器](https://czechiuu.github.io/cell-wrapping-actuator-simulator-pages/)

此仓库只发布静态构建产物；源码与完整测试保存在原源码仓库。

新版默认使用 Pd 200 nm / Au 260 nm，并由参考长度 30 µm、通电自由角约 180° 确定自由曲率。材料理论 EI 与探针实验独立保存：默认理论探针力约 43.104 µN，实验记录为 60 µN。实验等效模型需完成样品/驱动可比性及同姿态预载记录后再应用。

当前结构的结果仍是规定姿态下的近似反力与名义压强；完整接触解不成立时保留数值诊断，不显示伪造压强。

[计算方法、默认复算与模型范围](docs/model-audit.md)

发布验证：源码 84 项测试通过，生产构建通过。版本 0.3 保留主动铰链与执行器参数整合、逐节数值、CSV 与 JSON 导出。
