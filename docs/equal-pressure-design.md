# 等压设计：每块面板接近目标，而不只是超过下限

## 目标定义

对每块面板分别检查 |p_calc − p_target| / p_target ≤ tolerance。默认容差为5%；目标300 Pa时，每块面板均需落在285–315 Pa内。不能以整体平均压强达标代替逐面板达标，也不能要求第一块必须高于300 Pa而拒绝296 Pa的合格方案。

这一模式与“各板至少达到目标”的下限模式不同。新目标允许小范围低于目标，并且要抑制明显超压。结果应显示每板压强、相对误差、全体最大误差；未满足容差的最近候选不能标成达标。

## 固定量与可调整量

搜索固定铰链有效长度、单条金属宽度、可用带宽上限、Pd/Au厚度和模量、驱动参数、条间距、留边，以及用户给定的细胞直径和面板数量。可在明确范围内改变面板和底板尺寸、求接触转角、选取各处整数并联条数。

固定单条宽度并不意味着各面板面积也必须相同。不同面积的面板可以承受不同大小的法向力，却具有相同的名义平均压强。

## 基本计算

给定几何和整数条数，先求各铰链输出力矩，再通过同一有限弧运动学的有符号虚功矩阵求全部面板反力。p_calc,k = F_k / (L_k W_k)。

在现有径向对称、接触位于面板中线的模型里，单独改变横向面板宽度通常不改变接触位置、方向或力臂。因此可从固定整数条数的实际反力提出 W_k = F_k / (p_target,k L_k) 的宽度候选。但这只是生成候选的办法，仍需重新构建有限面板、完整求力，并检查宽度范围、相邻阵列承托和碰撞，不能假定所有几何都满足这种不变性。

若为了容纳阵列，宽度必须略高于上述值，压强会略低于目标；只要每块仍在允许偏差内，可以保留，而不必再把条数向上取整。

## 必须同时通过的检查

- 所有几何、材料、驱动及数量输入有效，条数是规定范围内整数。
- 面板与球体的候选接触、有限面板及铰链对球体的非穿透检查通过。
- 输出法向力非负，耦合力矩平衡成立。
- 各处条阵占宽落在固定可用带宽内；其两侧面板或根部底板能支撑对应实际占宽。
- 每块面板达到指定的压强误差范围。
- 有限刚性面板相互之间以及与底板的展开/包裹端态实体重叠检查通过；接触或共享边界不应误判为体积穿透。

可用带宽是排布包络，不能把整片包络当成实心金属条带。端态不相交也不代表从展开到包裹的整个运动路径无碰撞。

## 已独立验证的条件算例

细胞直径2000 µm、底板400×400 µm、每侧3块面板、铰链有效长度30 µm、单条宽15 µm、可用带宽300 µm、间距6 µm、两边各5 µm留边；沿用历史暂定材料和参考驱动。

容差方案：面板长度均150 µm；从根部到末端的整数条数11、5、1；面板宽235、401.085714754、341.903637868 µm。全链重新计算得到296.042808654、300、300 Pa，每侧一致，最大相对偏差约1.3191%。根部阵列占宽235 µm，因此不能把第一块面板缩到不满足承托的231.90 µm。

数值精确等压算例：面板长度均151 µm，宽241.219558271、390.603050003、339.639375365 µm，仍为11、5、1条。该规定姿态模型下12块面板均约300 Pa，数值差小于2×10⁻¹² Pa。此精度是数值计算结果，不是材料制造或生物测量精度承诺。

上述例子不构成真实细胞接触压力或制造可行性的独立证明。实际实现的搜索可能因范围、预算及候选排序返回另一组方案。

## 输出和应用

选择等压候选时必须保存该候选自己的整数数量和完整几何。应用到正向页面或导出时不能重新用旧的下限算法覆盖数量，否则可能把合格的296 Pa误判为不足并改变整个负载分配。

输入、目标、容差、搜索范围或材料发生变化后，旧候选必须过期或重新核验。搜索只承诺在当前范围和预算内找到的条件候选，不证明全局最优；若没找到满足全部条件的方案，应分别报告未达容差、几何、碰撞和排布约束，避免把预算用完说成物理不可能。
