# 固定铰链的几何优先设计

## 用户约束

固定已输入的铰链有效长度、单条金属宽度与可用排布带宽上限。材料、驱动状态、细胞直径和面板数量同样不能被几何搜索暗中改写。允许在明确范围内改变面板长宽、底板长宽，以及求出相应的铰链转角。

三个宽度必须区分：

- 单条金属宽度 w：参与单条 EI 和力矩计算。
- 可用排布带宽：容纳并联条带的上限，不代表该区域全部由实心金属组成。
- 实际排布占宽：n w + (n−1) g + 2 e，包含条间距 g 和两侧各 e 留边。

每块面板须支撑其相邻的入端和出端铰链阵列；根部底板须支撑该侧根部阵列。不能只检查阵列是否落在可用带宽内。

## 闭合计算顺序

1. 在用户允许的范围内生成候选面板、底板尺寸，优先接近原始尺寸。
2. 从真实底板边缘建立锚点，采用同一有限圆弧铰链运动学搜索几何接触转角。
3. 对候选姿态计算各面板面积和目标载荷 F = p A；从全部下游载荷求各铰链需求矩。
4. 计算整数并联数量及实际占宽；复核两侧支撑宽度与固定带宽上限。
5. 若面板宽度需要改变，重新计算面积、目标载荷、力矩、数量、接触和支撑，不能沿用旧面积的力。
6. 只有最终同一套尺寸、角度、整数数量通过所选目标和全部相关检查，才返回可用的条件设计候选。

搜索是有范围和计算预算的。未找到候选不等于证明任何尺寸都不可行。可用带宽内放不下所需条数时，必须报告约束冲突；不能自动增大固定带宽或单条宽度。

## 同一套几何用于显示和算力

将选定设计明确应用到正向页面时，应同时转移实际面板/底板尺寸、逐铰链转角、材料与驱动记录以及整数并联数量。显示、正向力学和导出必须使用同一套重建后的有限弧几何。

此后修改尺寸，应明确让原已求解姿态过期或重新求解。不能一面显示旧的“已贴合”状态，一面用新的尺寸或旧的估算角度计算压强。单纯修改驱动力学参数可在同一规定姿态下重新检查力平衡，但不证明新姿态自然可达。

## 坐标与支撑宽度

现有底板渲染为 X 方向 lengthM、Y 方向 widthM。前/后侧锚点位于 Y 边缘，其横向阵列沿 X，故根部横向支撑为底板 lengthM；右/左侧锚点位于 X 边缘，其横向阵列沿 Y，根部横向支撑为 widthM。矩形底板的锚点距离和横向支撑尺寸不能混用。

## 物理适用边界

刚性平面板与未变形球体的相切不代表整面接触；压力仍为完整面板面积上的名义平均值。几何候选不是自然弹性平衡、真实细胞变形或动态折叠路径。不同面板、不同侧及底板之间的全部碰撞，工艺锚接和释放结构仍需后续检查。固定带宽的可视化包络不应当作已经生成实际金属条带的制造版图。
