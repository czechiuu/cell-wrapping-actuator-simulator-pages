# 反向版图设计：目标载荷 → 各铰链并联条数

## 用途与范围

这一页用于已有面板—铰链布局的条件尺寸设计。用户给出每个面板的目标名义压强、面板长宽、各铰链有效弯曲长度和相对转角，以及 Pd–Au 材料、单条宽度和驱动参数。计算输出各位置的并联条数候选、排布占宽、转角余量和取整后的理论载荷复核。

“并联条数”是同一铰链处横向排布的条带数，不是沿弯曲方向首尾连接的串联节数。后者改变弯曲长度、柔度及全部下游几何，不能直接乘以单条力矩。当前反算不把这两种数量混在一起。

## 两种载荷定义

- 面板中心法向：在面板内侧面中心施加目标等效法向载荷，适合版图初步规划。即使结构尚未贴合球体，也能计算这个明确指定的载荷需求；结果不能称作真实球面接触压强。
- 球面候选接触：采用有限面板最近材料点及球心径向。只有相应几何与接触力检查通过，才能报告给定姿态下的条件接触反力。

两者都采用有限长度常曲率铰链的虚功力臂。不能以到转轴的无符号距离代替有符号力臂，也不能只考虑本面板，忽略全部远端面板的负载。

## 计算链

1. 面板 k 的目标载荷：F_target,k = p_target,k × L_panel,k × W_panel,k。
2. 规定姿态的有限弧运动学给出 r_jk；j 上游铰链承受所有 k ≥ j 面板的广义载荷。
3. 需求力矩：T_required,j = Σ(k≥j) r_jk F_target,k。此处未计入未指定的夹具、液体或其他外载荷。
4. 单条能力：M_one,j = EI_one,j × (κ0,j − q_j/l_j)。完整双层截面 EI 包含平行轴项。
5. 连续数量：n_continuous,j = T_required,j / M_one,j。力矩方向不兼容或非零需求但单条能力为零时，不生成假解。
6. 整数候选：向上取整并检查数量上下限。占宽 = n w + (n−1) g + 2 e，其中 g 为条间距，e 为两边各自的边距。
7. 用整数候选重新计算各铰链实际模型力矩，再解耦合串联平衡，报告各面板试算载荷与目标偏差。负法向力必须明确提示，不能截断为零。

## 整数数量不是精确压强保证

各铰链分别向上取整，并不保证同一驱动态下每个面板同时达到目标压强。近端载荷依赖远端实际力矩。某些组合甚至会产生负的上游试算法向力。条数候选是容量规划结果；必须检查取整后的耦合复核。

可计算每个铰链精确匹配目标力矩所需的 κ0,j = q_j/l_j + T_required,j/(n_j EI_one,j)。这只是诊断，不表示硬件具备独立调节各铰链曲率的通道；也不能假定曲率与 DAC 电压之间已经标定。

## 为什么正向页会没有有效值

原有姿态由几何估计角度后，使用有限弧铰链与刚性面板重新构造。该步骤不等于求解真实贴合或自然平衡。重建后可能留缝、穿入球体，或在力平衡中得到负法向力。改变杨氏模量或并联条数不会消除几何留缝或穿透。

诊断应显示具体侧面、面板、间隙/穿透量和试算力。仍可计算的 EI、自由角与输出力矩保留展示。不得通过放宽接触容差、关闭检查或给无效压强填零来掩盖问题。

## 实验与加工边界

当前历史驱动和模量记录仍是暂定值，保留可编辑来源与确认状态。输出是模型条件下的初步版图数量，不是制造验收结果。正式版图还需要实际加工线宽/间距、锚点与释放孔、供电连接、材料应变范围及驱动校准检查。名义完整面板面积平均压强不等于真实微小接触区域内的局部压力。

## 可选：逐板至少达到目标的构造法

如果目标解释为“每块面板至少达到指定名义压强”，且本模型该侧每个铰链的单条驱动力矩和自身对角力臂均为正，可从末端向根部构造另一组整数候选。先给末端选整数条数并求其实际试算力，再把这个已经取整后的远端载荷带入近端需求，逐步选择近端条数。它与各位置独立向上取整不同，能避免只满足单个需求矩、却遗漏取整后远端载荷的情况。

该构造法仍须满足每处排布上限，并重新核验全部目标下限、非负力及接触条件。它可能产生较大的超出量，不保证精确命中目标，也不声称全器件条数全局最少。不满足受支持符号条件时应明确报不支持，不能暗中把结果当作保证满足的解。
