# 理论模型核对

核对对象为原发布版本 `842d50e36a56f8c661c2522b71d8d13884ceb051`。这次核对保留其力学核心，修正界面参数解释、结果可见性和模型适用范围。

## 1. 12.76° 的来源是教学参数，不是角度上限

| 项目 | 数值 |
| --- | ---: |
| Pd / Au 厚度 | 100 / 100 nm |
| Pd / Au 杨氏模量 | 120 / 80 GPa |
| Pd / Au 自由伸长应变 | 0.001 / 0 |
| 金属总宽度 | 9 × 15 = 135 µm |
| 裸露弯曲段长度 L | 30 µm |
| 中性轴 zN（从 Au 顶面向 Pd） | 110 nm |
| EI | 8.73 × 10⁻¹⁵ N·m² |
| 主动弯矩 | 6.48 × 10⁻¹¹ N·m |
| 自由曲率 κ₀ | 7422.680412 m⁻¹ |
| 自由转角 θ₀ = κ₀L | 0.222680412 rad = 12.758648° |

这些值与给定逐层积分推导的教学例一致，没有将弧度误当角度，也没有把并联根数漏乘。

并联宽度同时乘入 EI 和主动弯矩，因此在自由曲率的比值里抵消。增加并联条数会增加输出力矩，不会将自由转角乘以条数。

同样 30 µm 有效长度若自由转过 180°，对应 κ₀ = π/L = 104719.755120 m⁻¹。在同样层厚与模量的线性模型下，对应等效应变差约 1.410808%。这是参数对照换算，不证明实际电化学驱动会产生该应变，也不能代替对初始曲率、材料及工作状态的测量。没有根据此对照自动改变默认参数。

## 2. 逐层本构与符号

Au 在上，Pd 在下；厚度坐标 z 从 Au 顶面向 Pd 为正，朝 Au 弯曲为正曲率。

各层实际纵向应变：

\[
\varepsilon(z)=\varepsilon_N+(z-z_N)\kappa
\]

各层应力：

\[
\sigma_i(z)=E_i[\varepsilon_N+(z-z_N)\kappa-\varepsilon_i^*]
\]

中性轴按各层 E×截面积加权。EI 是各层关于该轴的 E×截面二次矩之和：

\[
EI=\sum_i E_i W\left[\frac{t_i^3}{12}+t_i(z_i-z_N)^2\right]
\]

其中 W 为并联金属总宽，tᵢ 为层厚，zᵢ 为各层中心深度。

主动弯矩由本征应变的逐层力矩贡献得到：

\[
M_{\rm act}=W\sum_i E_i t_i(z_i-z_N)\varepsilon_i^*,\qquad
\kappa_0=\frac{M_{\rm act}}{EI}
\]

当前实现与上述关系一致。测试另用层中心和平行轴公式验证不等厚、不等模量情形，并检查相同本征应变时自由曲率为零、应变差反向时曲率反向。

## 3. 有限长铰链：平均曲率不等于处处曲率

每段长度 L 只包含能弯曲的裸露金属，不包括刚性面板。当前实现用几何指定的相邻面板转角差 θ 得到：

\[
\bar\kappa=\theta/L,\qquad
\bar M_{\rm out}=EI(\kappa_0-\theta/L)
\]

EI 与 κ₀ 沿段长均匀时，这是平均曲率及平均输出弯矩关系。若要求局部曲率或局部应力，需要沿弯曲段求出 κ(s)，不能把这一个平均量当作所有位置的值。

原代码字段 `actuatorLengthM` 只存在于旧版占位模型的参数中；在 Pd–Au 解析模型中，真正参与 θ₀ 与 θ/L 的是 `hingeLengthM`。解析模式使用一个明确命名的有效长度输入，避免把两者当成两段独立构件。

## 4. 串联平衡方向正确；力臂采用近似

第 j 节铰链必须承担第 j 至末端所有面板的载荷：

\[
\bar M_j=\sum_{i=j}^{n}F_i\bar r_{ji}
\]

原代码的上三角反代包含全部远端贡献，带符号叉乘力臂的方向与其力矩定义一致。测试核验每一行的力矩平衡残差。

但有限长铰链严格需要沿实际受载曲线平均的力臂：

\[
\bar r_{ji}=\frac1{L_j}\int_0^{L_j}r_{ji}(s)\,ds
\]

当前代码使用示意铰链中点处的中性轴参考点计算 r。对直线、均匀截面的参考段，这与几何平均点的力臂一致；对发生明显弯曲的有限长铰链，它只是近似。代码未求出实际 κ(s) 和中性轴曲线，不能声称已精确实现上述有限长积分。界面已标明“平均输出力矩”“中点近似力臂”。

## 5. 几何指定姿态与实际接触平衡不同

默认几何的第一节转角约 129.58° 是几何算法指定的相邻面板转角差。它不是用材料驱动能力、细胞反力及接触条件联立求出的真实停止角度。

该默认状态下，前侧平衡试算力约为 −9.377846、0.938838、−0.074568 µN；其他侧因对称性相同。无黏附接触无法提供拉力，因此原代码将每侧整个解判为无效。保留这一判定，不能取绝对值、截成零后继续沿用原姿态，或把正的局部试算值当作整侧有效解。

即使试算力全部为正，程序也未同时满足真实接触互补条件。默认前侧几何接触标签还包含间隙和穿透。因此目前 p=F/完整面板面积只给出指定姿态下的近似名义载荷，不是实际细胞压强预测。

下一阶段若要预测实际停止姿态，应联立求解：铰链受载曲线、面板刚体位姿、细胞的力—变形关系、接触/脱离条件，以及需要时的残余初始曲率。它需要额外物理输入，不能靠把默认角度改成 180° 解决。

## 6. 已完成的验证

- 逐层截面结果与上述教学值一致。
- 当输入 θ = 0.12 rad、平均力臂 250 µm、面板 400×400 µm² 时，独立复算得到平均弯矩 2.988×10⁻¹¹ N·m、接触力 0.11952 µN、名义压强 0.747 Pa。
- 长度增加一倍使自由转角增加一倍；并联金属宽度增加一倍使 EI 与力矩增加一倍，自由曲率不变。
