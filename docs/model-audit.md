## 材料理论主模型

从 Au 顶面开始，z 朝 Pd 为正，朝 Au 弯曲取正。两层的截面形心为 zAu = tAu/2、zPd = tAu + tPd/2。

- zN = Σ(Ei Ai zi) / Σ(Ei Ai)
- Ii = W[ti³/12 + ti(zi − zN)²]
- EI理论 = EAu IAu + EPd IPd
- κ₀ = θ参考 / L参考；θ₀,j = κ₀ Lj
- Mj = EI,j(κ₀ − θj/Lj)

默认复算：zN = 253.214285714 nm，IAu = 7.30609783163×10⁻²⁵ m⁴，IPd = 3.97886096939×10⁻²⁵ m⁴，EI理论 = 1.06195114286×10⁻¹³ N·m²，κ₀ = 104719.755120 m⁻¹，平直约束驱动力矩为 11.1207263629 nN·m。

因此，30 µm 裸露段的自由角为 180°，20 µm 段为 120°。宽度和条数改变 EI 与力矩，不改变相同截面及驱动状态下的自由曲率。不会将所有长度的自由角硬设为 180°。

参考曲率只自动转用于相同层厚和模量的当前设计；若修改这些参数，需切换为该截面自己的已测曲率或本征应变输入。独立的参考实验不会自动覆盖。原有本征应变与直接曲率模式仍保留。

### 应变含义

材料理论反算的等效 Δε* = 3.214215473%，不是实测 Pd 自由应变。上下表面的总应变跨度 tκ₀ = 4.817108736%，与 Δε* 不是同一个量。

自由态层内应力只在“两层均匀本征应变、沿长度均匀自由曲率、轴向外力为零”的材料线弹性假设下估算。较大的估算弹性应变提示小应变与材料线弹性假设需要实验核对。本版没有加入塑性、脱层、电化学动力学或被动 SU8 层的抗弯刚度。实验等效 EI 不用于反算层内应力。

## 探针独立对照

给定位置力矩 M参考 = F d。默认读数对应 15.48 nN·m；不能在未记录几何的情况下把这一数值当作每个截面的恒定力矩。

点铰链近似：M预测 = EI理论(κ₀ − θ测试/L参考)，F预测 = M预测/d。默认理论力为 43.1035905539 µN，低于记录的 60 µN 约 16.8964094461 µN（28.1607%）。理论结果不会被探针读数自动替换。

有限长铰链应使用 r̄ = (1/L)∫r(s)ds。界面允许输入由测试几何另行求得的平均力臂；不给出时不伪造平均力臂，不自动将 258 µm 减去 L/2。原参考位置的 Fd 与所选平均力臂的 F r̄ 分别保存。

## 可选实验等效模型

在同一样品、同一驱动状态、同姿态预载处理明确、线性力矩—转角关系及选定力臂模型假设下：

EI等效 = F净 r模型 L参考 / (θ参考 − θ测试)。

默认实验的条件候选值为 1.47823111144×10⁻¹³ N·m²；参考样品曲线为 M(θ) = 15.48(1 − θ/π) nN·m。因此 90° 为 7.74 nN·m，180° 为零。这条中间角度曲线是模型预测，尚非实测曲线。

未核对样品/驱动状态或预载时只显示候选值，不应用于包裹计算。选择应用后，材料理论 EI 仍独立保留；不得与单独本征应变驱动混用。相同层厚、模量和参考驱动下，允许按总金属宽度线性缩放等效 EI。无效参考角、力臂、净反力或不一致截面返回明确无效状态。

## 包裹模型的范围

当前几何程序指定最终姿态，再按串联力矩平衡求反力：Mj = Σ(k≥j) Fk rjk。有限长铰链平均力臂在此仍以示意中点近似，没有重建受载曲线。

细胞的力—变形关系未提供，因此结果是**规定姿态下的近似反力与完整面板面积名义压强**，不是细胞接触变形的耦合平衡解。尚未联合求解非穿透间隙 g≥0、单侧力 F≥0 与 Fg=0；几何间隙或穿透也不能当作已真实接触。

当前默认三节同曲率结构的部分平衡试算力为负，不满足只压不黏附的完整侧面接触假设。曲率、自由角、规定角、EI、力矩、力臂和诊断试算仍显示；有效力、压强及总量不伪造为零。教学示例仍可载入，但其 100/100 nm 层厚及逐节曲率为教学输入，不是当前器件实验结果。

JSON 保存 SI 输入、参考实验、未知/已确认状态、刚度来源与计算快照；CSV 保留逐节数值、试算力、模型来源和参考探针对照。
