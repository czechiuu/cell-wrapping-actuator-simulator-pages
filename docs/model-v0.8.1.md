# v0.8.1：四臂 C4 旋转对称与实际金属条阵

本版修复 v0.8 搜索可能给四臂不同解、以及 3D 将整个可用带宽画成实心铰链的问题。力学方程、名义压强定义、接触模型和 v0.8 的有序子午线到达条件不变。

## 对称的含义

- 底板 X/Y 尺寸相等；四个根部由同一半径绕球心旋转 0°、90°、180°、270°得到。
- 四臂同编号面板的长、宽、厚，铰链有效长度、几何厚度、转角与排布带宽相同。
- 同编号铰链材料层厚、模量、驱动、单条金属宽与并联条数相同，对应面板目标压强相同。
- 同一条臂不同编号的面板和铰链可以不同；例如宽度 216.885 / 155.735 / 305.028 µm 与条数 7 / 4 / 1 是允许的。

搜索以单个代表臂为变量，将同一组尺寸、转角与整数配置旋转复制到其余三臂，然后重新建立完整器件并验收。不会先搜索四个不同方案，再平均尺寸或条数。

旧的非对称输入可供诊断，但不被当作本版有效对称候选。非对称目标、材料驱动或逐位置覆盖会明确报告问题，不静默删除。界面同编号修改同步四臂，底板两维同步；输入变化使旧选择过期。选择、应用与导出重新检查实际几何和配置，不只相信保存的成功标志。

## 合格条件

C4 对称是额外硬条件，不取代任何原有验收：四臂各自有效有限面板切点递增，末端默认达到底极起算 90°；每块板名义压强分别处于目标 ±5%；有符号 Jacobian 串联耦合反力非负、力矩残差足够小；有限板和铰链对球无穿透；整数条阵满足固定带宽、间距及留边，并被相邻两块板和根部底板承托；展开及包裹终点刚性板/底板碰撞检查通过。

完整定义与历史数值例见 [v0.8 模型说明](model-v0.8.md)。D600 µm / 300 Pa 是独立验证例，不能替代原 D2000 µm / 300 Pa 任务。未找到合格方案只说明有限范围与预算内未找到，不是全局无解证明。

## 实际条阵渲染

渲染使用同一正向快照解析的逐铰链整数 N 和单条宽 w，以及规定设计间距 g、边缘留白 e。实体金属横向跨度为 Nw+(N−1)g；含留边的排布需求为 Nw+(N−1)g+2e。整组在可用带宽中心对齐，各条间隙和边缘留白为空。N=1 时只绘制一条；条数或排布缺失、无效、超出带宽时显示线框包络，不用整个带宽冒充实体，不缩放金属宽度强行塞入。

渲染仅改变显示，未修改 EI、单条输出矩、并联倍率或接触力计算。几何铰链厚度与 Pd/Au 材料层厚仍是各自原有参数，不能从示意图直接读出纳米层厚。

## 边界与版本

仍是规定姿态下的条件模型，不求自然平衡、未知接触活动集、细胞变形、局部真实压力场、连续接触面积、稳定性或完整运动路径。端态刚性面板检查不包含真实金属条间制造/碰撞验证。
