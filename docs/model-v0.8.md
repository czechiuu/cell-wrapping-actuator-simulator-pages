# v0.8：逐板等压与四臂有序子午线接触延伸

## 变化与不变

v0.8在v0.7等压判据之外加入真实几何门槛：四条臂均须以有效切点从底部向侧面延伸。没有改成真实细胞压力求解，也没有增加自然平衡、细胞变形、连续接触集合、稳定性或全折叠路径求解。

仍按完整材料截面EI → 自由曲率 → 规定有限铰链转角 → 输出矩 → 同一运动学的有符号虚功矩阵 → 面板反力 → 名义板面积压强计算。压力为F/(板长×板宽)，不是局部压力场，也不是用真实接触面积算得的压力；各板压力不能相加。

## 可核验的接触延伸定义

球心为原点。每块有限面板从其实际变换重新计算内表面最近点，并检验内表面切平面、有限切点位置、球面间隙及板实体非穿透。旧缓存接触字段、用户显示接触容差、面板中心、累计转角或投影到球面的提示点都不能代替有效切点。

实际切点c=(x,y,z)的极角为：

θ = atan2(sqrt(x²+y²), −z) × 180/π。

底极0°、赤道90°、顶极180°。每条臂按根部至末端的板序验收：

1. 每块面板都有实际有效切点，链条编号完整。
2. 相邻切点满足θ(k+1)−θ(k)>εθ，避免重合、倒序和数值误差内的伪推进。
3. 末端切点满足θ末+εθ≥θ要求。

默认θ要求=90°，εθ=0.00001°。用户门槛范围0–180°；独立数值角容差范围0–0.001°。非有限数和越界值在搜索前拒绝。这个角容差与±5%压力容差、几何显示接触容差互相独立。

输出包括每臂各切点坐标/极角、起点极角、终点极角、首末角跨度Δθ及子午线弧长RΔθ（弧度）。它们描述离散切点的延伸范围，不代表面板之间的球面连续接触，不是球表面积覆盖率，也不要求消除四臂之间的空隙。

## 完整合格条件

以下条件必须同时成立，任一臂失败则整体失败：

- 上述四臂有序实际切点及末端门槛。
- 有限面板、有限常曲率铰链和球体的接触及非穿透。
- 有符号Jacobian串联耦合反代的非负反力和足够小的归一化力矩残差。
- 规定范围内整数条数、固定可用带宽、条间距和留边；根部底板与相邻两块板都能支撑实际阵列占宽。
- 每块板分别满足|p−p目标|/p目标≤0.05（或用户指定压力容差）。300 Pa时12块板各自须在285–315 Pa内，平均值无替代作用。
- 展开端态和包裹端态的刚性面板/底板碰撞检查通过。

固定可用带宽是排布包络，不应当作整片实心金属。端态碰撞通过不代表全过程无碰撞，也不包含实际金属条带间的碰撞与制造验证。

## 有界搜索和结果可信度

每次搜索固定四条臂和明确的每臂板数；铰链有效长度、单条金属宽、排布带宽上限、材料厚度/模量、驱动、间距、留边都不会为搜索成功而暗改。允许范围内的底板/板尺寸和整数条数参与搜索，转角由真实有限铰链接触重算。

为提高预算利用，角度/半径估计可生成较长面板的初始提案，但提案不算合格证据；必须用实际有限实体切点重新验收。宽度F/(p目标L)也只是提案，之后完整重建、耦合正算、支撑、碰撞及延伸判据都需重算。

搜索受候选、分支、整数试算、时间和束宽预算约束。找到第一个完整合格方案即可停止；未找到时可报告已检查的硬约束合格近似，但不得标成等压成功、不得据此宣布物理无解。输入或判据改变后旧结果过期；应用/JSON保留该候选的精确整数与当前判据、逐臂诊断，避免用旧下限向上取整覆盖。

## 验证例A：600 µm球，侧面延伸与300 Pa均通过

这是为v0.8验收建立的不同输入验证例，不是把2000 µm任务悄悄改成600 µm。

- 四臂，每臂3板；D=600 µm，底板240×240×20 µm；各板长150 µm、厚20 µm。
- 铰链有效长度30 µm、几何厚10 µm、排布带宽300 µm；单条宽15 µm；间距6 µm、每边5 µm。
- Pd/Au厚200/260 nm，暂定模量120/80 GPa；沿用参考自由角驱动（30 µm参考长度，180°），未为本例调刚度或驱动。
- 根部至末端条数7/4/1；宽216.8851584710011 /155.73511832566586 /305.028403188404 µm；实际阵列占宽151/88/25 µm。
- 每臂实际切点37.9038264063° /73.8326580896° /100.9062223091°。
- 相邻角增量35.9288316833° /27.0735642196°；首末跨度63.0023959028°，弧长329.879773545 µm。
- 全部12板名义压力约300 Pa；前臂反力9.7598321312 /7.0080803247 /13.7262781435 µN。
- 有限切点位于板内，板/铰链对球不穿透；整数排布、相邻支撑、展开/包裹端态碰撞均通过。

测试对全部四臂的有符号矩阵项另用独立二维有限弧积分和固定材料点中心差分验证，不重拟合接触点；同时检验串联耦合力矩残差。完整搜索在默认96候选、1.5秒等预算内找到合格方案，但浮点排序可能返回其他同样合格的整数/宽度组合，不承诺始终选中这组唯一整数。

## 原2000 µm / 300 Pa任务：尚无合格结果

原v0.7近底部11/5/1、L150 µm或151 µm算例可以让各板压力接近300 Pa，却没有到达侧面的终点切点，故v0.8默认拒绝。保留显式0°门槛的历史测试只为隔离原力学回归，不作为新默认通过样例。

本次单独复核保持D2000 µm、四臂、每臂3板、L铰链30 µm、单条15 µm、固定带宽300 µm和同一材料/驱动/间距/留边：

- 默认尺寸范围与预算：96个几何候选全部未通过完整接触/侧面延伸检查，整数试算0次。结果为not-found，候选预算用尽。
- 扩展复核：板长/宽10–1000 µm，底板长/宽10–1200 µm；最多512几何候选、16384分支、2000000整数试算、10秒、束宽64。
- 该次运行143个几何候选、791次接触计算、90664次整数试算后达到16384分支预算。返回的已检查硬约束合格近似为底板800×800 µm，板长454.722083345649 µm，宽298/46/25 µm，条数14/2/1。
- 其实际切点42.2079475351° /55.8063709927° /95.0651469638°，支撑、接触、端态碰撞通过；压力182.433333 /124.408734 /234.381611 Pa，最大相对误差58.5304%，远超±5%。结果仍为not-found，不得应用为合格等压设计。

这些是指定输入/范围/预算下的观察，不是全局最优或不可能性证明。600 µm通过只说明新判据有一个内部一致的正例，不能证明2000 µm需求完成；未改变材料/驱动来伪造该完成结论。
