# v0.7 等压设计验证

日期：2026-10-15。本记录区分模型数值核验、代码测试和实际网页验证。

## 核心目标

每块面板独立满足目标相对偏差，默认±5%；300 Pa对应285–315 Pa。明确区分等压目标、旧的逐板最低压强，以及仅计算力矩容量的整数种子。等压候选应用到正向时必须保留自己的整数条数，不能再被下限算法改写。

## 独立数值算例

1. 直径2000 µm、底板400×400 µm、每侧3块长150 µm面板；固定铰链有效长度30 µm、单条宽15 µm、可用带宽300 µm、间距6 µm、各边5 µm。整数11/5/1条，面板宽235/401.085714754/341.903637868 µm，全链重新计算得到296.042808654/300/300 Pa，每侧相同，最大偏差1.3191%。
2. 保持同样固定参数，面板长度151 µm、宽241.219558270624/390.603050002830/339.639375365237 µm，同样11/5/1条，在规定姿态模型中可得到数值精确的300 Pa。
3. 使用12/5/1条并直接按300 Pa换算宽度558.4597396/401.0857148/341.9036379 µm，虽然力学数值达标，但会跨侧互撞，必须拒绝为合格等压方案。

独立小规模枚举：固定151 µm面板长度、带宽最多14条、各板宽限制20–500 µm，枚举14³种对称整数配置。存在满足支撑并通过展开/包裹端态碰撞检查的11/5/1方案。150 µm长度下应允许将根板精确等压宽度231.9002 µm提高到必要支撑宽235 µm，接受296.04 Pa在±5%以内；不能仅因低于300 Pa而拒绝。

## 端态实体碰撞

新增有限刚性矩形体 OBB SAT，检查每块面板与其他面板及底板，在展开和包裹两种端态是否发生超过容差的实体重叠。使用与显示相同的宽/长/厚及旋转定义，包含15个分离轴，允许合法面接触/边接触。基础碰撞模块23项测试通过，包括小尺寸、旋转、矩形底板、接触和穿透。

558.46 µm根板例在两个端态各有4个邻侧碰撞，共8项；235 µm根板例通过端态检查。整条折叠路径、真实铰链条带、导线与锚点的全部几何碰撞仍不在此检查范围内。

## 状态与输出要求

每次检查都使用完整新几何和实际选定整数数量进行正向计算，保留每板目标、实际压强及偏差。不满足几何、负力、支撑、带宽或端态碰撞的方案不能作为合格候选。未达到压强容差但其他硬条件通过的方案可以作为明确标记的近似候选，不得显示达标。

导出应记录目标类型、容差和搜索诊断。更改目标、容差、尺寸范围或驱动后，旧搜索结果要失效；不得把过期方案一键应用成当前已验证设计。

## 限制

这些结果使用暂定模量与尚待核对的历史驱动记录，仅证明当前模型中的条件可行性。名义面板面积压强不是实际接触区压力；数值精度不是制造精度。未证明未知自然平衡、细胞变形、稳定性、全过程避碰或可直接制造。云浏览器缺少WebGL2时，不能声称GPU 3D视觉验收通过。
