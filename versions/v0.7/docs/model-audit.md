# v0.4：材料截面 → 自由曲率 → 规定姿态 → 接触反力

本页是简要实现约定，不是原教材的副本。理论来源为用户提供的《Pd Au 双层微铰链与多面板包覆结构：完整路线版》（2026 年 10 月），主要对应第 2–10、13–14 章。本文版本为 v0.4；历史参考数值是暂定输入，不代表已完成器件标定。测试和发布状态应以对应提交的验证记录为准。

## 1. 坐标与完整截面

Pd 在下、Au 在上；z 从 Pd 底面向 Au 增大，正曲率朝 Au。此坐标原点与 v0.3 文档不同，不能直接混用旧版 zN 数值。

- h = tPd + tAu；zPd = tPd/2；zAu = tPd + tAu/2
- ε(z) = εN − κ(z − zN)；σi = Ei(ε − εi*)
- zN = (EPd tPd zPd + EAu tAu zAu)/(EPd tPd + EAu tAu)
- EIone = w Σi Ei[ti³/12 + ti(zi − zN)²]
- 相同条带并联：EItotal = n EIone

平行轴项不可省略；不能以任意平均模量乘总厚度惯性矩替代复合截面。以下 EI 指所讨论铰链的总并联刚度。内部使用 SI：m、Pa、rad、N、N·m、N·m²；应变无量纲，曲率单位 m⁻¹。

## 2. 三个互斥的驱动入口

一次计算只能采用一个入口：

1. 本征应变差 Δε = εPd* − εAu*。由材料截面求 κ₀：

   EIone κ₀ = w [EPd tPd EAu tAu/(EPd tPd + EAu tAu)] [(tPd + tAu)/2] Δε。

2. 当前截面、当前驱动态的自由曲率 κ₀，直接输入。
3. 参考自由角 θfree,ref 与参考有效长度 lref，取 κ₀ = θfree,ref/lref。

自由形状入口要求真正无外部机械限制；“未通电”或“看起来弯了 180°”本身不能证明该条件。由 κ₀ 反算的等效 Δε 仅属于本材料模型，不能标作实测 Pd 本征应变。两层共同增加相同本征应变，不改变自由曲率。

各铰链分别计算 θ₀,j = κ₀,j lj。修改设计铰链长度不能改写参考长度，也不能使所有铰链始终保持 180° 自由角。固定截面与状态时，改变条宽或并联数只改变 EI 与力矩，不改变 κ₀。

参考自由角不能自动转用于不同层厚或模量；该不匹配应返回明确无效状态。改用直接曲率输入时，用户是在为当前设计提供新的曲率假设，仍需核对截面和状态。选择本征应变入口改变厚度时，EI 与 κ₀ 必须同时重算。

## 3. 姿态决定输出力矩

内部截面矩 M = EI(κ − κ₀)，对外输出矩取反号。常曲率集总铰链使用：

- κj = qj/lj
- Mout,j = EIj(κ₀,j − qj/lj) = (EIj/lj)(θ₀,j − qj)
- Uj = EIj(qj − θ₀,j)²/(2lj)

自由姿态输出为零；平直姿态给出条件堵转矩；超过自由角后力矩可反向。角度与曲率允许有符号，不应通过取绝对值消除不相容结果。

这仍是材料小应变、线弹性、完美黏结、细长梁与常曲率近似。允许大转角不等于允许任意大材料应变。自由态应力估计中的零轴向外力条件，不能自动搬到接触受限状态。

## 4. 有限长常曲率铰链与虚功

几何以弹性中性轴上的有限圆弧链为参考，不把整条铰链压成一个点。示意铰链显示厚度不进入中性轴路径或金属 EI；非零历史安装偏移若没有一致的偏移运动学，应阻止物理载荷输出。以初始切向 +Y、正弯曲方向 +Z 为局部坐标，长度 l、相对角 q 的弧段末端位移为：

- d(l,q) = (0, l sin(q)/q, l[1 − cos(q)]/q)
- q → 0 时 d → (0,l,0)，∂d/∂q → (0,0,l/2)

小角度应使用连续极限或稳定级数。接触位置 xk 必须由同一套弧段和刚板运动学得到。改变 qj 时，导数包括该弧段末端的平移及全部下游结构的转动：

- ∂xk/∂qj = Rupstream,j ∂d(lj,qj)/∂qj + aj × (xk − xend,j)，k ≥ j
- Jkj = −nk · ∂xk/∂qj
- T + Qother = JᵀF

nk 是细胞对面板的反力方向；面板对细胞的力方向与它相反。J 的行对应接触、列对应铰链；rjk = Jkj。不能用无符号欧氏距离或一个全局力臂代替它。

规定姿态下，每板一个标量法向接触且没有其他外载荷时，从末端回代：

- Tj = Σk≥j rjk Fk
- Fj = [Tj − Σk>j rjk Fk]/rjj

若姿态实际上由夹具保持，夹具广义反力不能默认消失；未知的 Qother 会使该力分配不完整。有限圆弧提高了集总运动学的一致性，但不是一般端力作用下的连续受载梁解：端力导致明显非均匀曲率时需要升级模型。

## 5. 接触检查与压力边界

规定姿态必须检查整个有限内侧矩形面及有厚度面板实体相对球体的间隙；只检查面板中心或把点投影到球面不足以排除穿透。接触点取有限内侧矩形上最近的材料点，可位于边缘；反力取该点相对球心的径向，Jacobian 使用同一材料点与方向。实体检查还要排除背面或边缘穿透。接触检查的“整块面板”不表示平板与刚球已全面贴合。

无黏着接触要求非穿透、压缩法向力非负及接触状态相容。间隙、穿透、奇异力臂、负试算力或平衡残差超限，均应阻止该侧不成立接触集合的有效力与压力输出；保留可计算的截面、力矩与试算诊断，不把失败结果改成零，不逐个截断负力后保留原解。

此版本的范围是**给定姿态下的条件反力检查**。它没有联合求解未知姿态、活动接触集合与细胞变形，也不是有限元分析或局部接触压力求解。即使某个规定姿态通过检查，也不能据此宣称它是器件自然达到的稳定平衡。

面积换算放在最后：pnom,k = Fk/(Lpanel,k Wpanel,k)，标签为“名义完整面板面积平均压强”。这不是真实接触区域平均压力，也不是面板内压力分布。完整有效结果的面积加权平均为 ΣFk/ΣAk，不把各面板压力相加；力大小之和也不是矢量合力。结果不完整时，不把有效子集冒充全器件总量。

## 6. 历史暂定记录与独立探针对照

参考输入：Pd 200 nm、Au 260 nm；EPd = 120 GPa、EAu = 80 GPa（均为假定模量）；w = 15 μm、n = 9、lref = 30 μm。自由角约 180° 作为同驱动态、真正自由条件尚待核对的参考假设。

由这些输入得到：

- zN = 206.785714 nm；EIone = 1.1799457143 × 10⁻¹⁴ N·m²
- EItotal = 1.0619511429 × 10⁻¹³ N·m²
- κ₀ = 104719.755120 m⁻¹
- 9 条平直输出矩 = 11.120726363 nN·m
- 用 258 μm 垂直力臂作独立单接触换算，F预测 = 43.103590554 μN

历史探针记录是 60 μN × 258 μm = 15.48 nN·m，关于所报告参考点；“面板压平”与铰链实际角、驱动态、参考点、预载和其他接触仍需核对。该记录比上述条件预测高约 39.20%，不能因此断言两次实验已矛盾，也不能同时用 180° 和 60 μN 暗中拟合主模型。

主模型使用材料 EI，探针只作独立对照。历史实验等效 EI 若被显式选择，属于另一个有条件的模型：必须核对状态、预载、姿态和力臂，明确标记来源；它不是对材料 EI 的第二份独立验证，也不能与独立本征应变驱动混用。

## 7. 可编辑记录、来源和下一步

参考实验与当前设计应独立保存。现有记录可编辑参考长度/自由角、材料截面、条宽/并联数、模量来源，以及探针读数、姿态、力臂和参考位置。状态字段区分同驱动态是否确认、预载未确认/已是净读数/需扣除。有符号力臂可以为负，但不能为零。

参考记录接口增加可选的 schemaVersion（当前为 1）、recordLabel、sourceNote、driveStateNote 和 freeBoundaryStatus；自由边界状态为 unconfirmed / confirmed / rejected。其用途是保留用户输入的版本、标签、来源和状态说明，并随参考记录导出。modulusSource 继续区分 assumed / measured，sameDriveState 继续区分 unconfirmed / confirmed / different。历史默认应明确标为暂定、假定模量、驱动态与自由边界未确认。

本文或记录的版本号不等于实验已完成溯源。未填写或未核实的样品、驱动条件、自由边界与薄膜模量应保留“暂定/未确认”语义；来源文字或导出不能自行把它们升级为已标定。

下一次最有价值的记录是：样品及测试日期、明确电化学状态、同状态无约束自由形状、受限时实际铰链角、有效铰链长度与并联数、薄膜厚度/模量、接触位置与法向、力的参考点/作用线、预载及其他约束。若要报告真实接触区平均压力，还需真实接触面积；若要预测自然姿态，还需细胞本构和边界条件。

最少回归检查包括：零失配、共同应变平移不变、自由姿态零力矩、宽度/并联数线性缩放、长度改变自由角、参考材料不匹配、探针修改不影响材料主模型、Jacobian 有限差分、零角圆弧极限、整块面板穿透/间隙、负力与奇异力臂、平衡残差及导出空值。
