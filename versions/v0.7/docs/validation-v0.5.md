## 独立数值交叉核验

1. 单板平直例：150×300 µm 面板、30 µm 铰链、15 µm 单条宽、Pd 200 nm/Au 260 nm、κ0=π/(30 µm)、暂定模量120/80 GPa。1000 Pa 目标需求4.05 nN·m；单条矩1.235636 nN·m；连续条数3.277664，取整4条；5 µm条间距与两侧各5 µm边距时占宽85 µm。回算1220.381494 Pa，比目标高22.038%。
2. 两面板耦合例：独立容量取整[3,2]得到[−1.606667,1.98] µN，负力被保留为无效诊断；目标下限构造[5,2]得到[1.282222,1.98] µN，均高于各1 µN目标。
3. 实验等效归一化：参考总矩15.48 nN·m/9条→每15 µm单条1.72 nN·m；当前30 µm条宽→3.44；局部7.5 µm→0.86，历史本地覆盖数量不污染单条能力。
4. 几何接触：400 µm球、220 µm方底板、150×100×20 µm面板与30 µm铰链可找到12面板接触候选；旧800 µm方底板例在限定搜索中不成功。不能据此声称自然受力平衡。
5. 铰链实体间隙独立随机核验：2000组，每组1001采样点，含极小转角；解析最小间隙的最大高估约2.17×10⁻¹⁹ m。
6. 目标下限构造随机核验：250组三铰链带符号耦合，242组可行且全部达到目标下限，8组按约束报告不可行。该方法不声称全局最小总条数。
